Member: We want to publish a short note on our colony-measuring protocol and post our own script on a public code site under an open licence. Does anyone's patent stand in the way?
Clear: no freedom-to-operate surface in publishing a protocol note and your own script under MIT; one clock to know about. No database searched.

Publishing a note and releasing your own code are not acts a patent reaches.
No database was searched, so record this as "nothing to search", not as a checked, clear field.
Publishing starts a clock: the US and Canada give you 12 months to file a patent of your own.
Europe and China give essentially none; check with the Research & Innovation Office before posting.
The licence is yours to grant on code you wrote; check the licences of the code it builds on.
If you later sell it as an app, a service or a device, ask again for a real search.
